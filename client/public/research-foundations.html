文獻支持的改進方向

Paper-supported improvement candidates

以下為待驗證的建議，不是新部署結果，也不直接把外部 benchmark 當作 NewsAgg 的提升。報告附錄 G 提供完整對照。

These are proposed tests, not newly deployed results or transferred benchmark gains. Report Appendix G provides the full mapping.

  1. 先釐清定義與完成裁決

    情緒不等於對象立場 [22]；標註一致性有其限制 [24]。先統一語氣、事件方向、立場的標準，裁決 93 篇分歧並保留原始標籤；開發與測試分離 [13]。

    First align tone, event direction and target stance; adjudicate 93 disputed articles while preserving original labels and separating development from test data. This is an evaluation priority, not a promised numeric gain.

  2. 比較現有混合檢索與單一路徑

    RRF 的 pilot／TREC 實驗平均約改善 4–5%，但有例外，量測為檢索 MAP [17]。本站已有 BM25 + dense BGE-M3 + RRF；以相同人工判定段落比較三者的前四段相關性及延遲。

    RRF reports roughly 4–5% average improvements in pilot/TREC retrieval experiments, with exceptions. NewsAgg already has rank fusion. Compare BM25-only, dense-only and fusion on the same judged passages; the published improvement is not a local result.

  3. 驗證摘要的去重與資訊涵蓋

    MMR 的 SUMMAC 1998 query-relevant 摘要 F-score 為 0.73，並非本站分數 [14]。相同長度下比較 lead sentences、只依相關性及現行 MMR 型方法，人工檢查涵蓋、重複與脫離語境。

    MMR reports F-score 0.73 for query-relevant SUMMAC summaries, not NewsAgg. Compare lead sentences, relevance-only and the existing adapted MMR under equal length limits, reviewing coverage, repetition and context.

  4. 用獨立開發資料改善 NLI 類別描述

    Laurer 等人的八項任務在 100–2,500 筆微調標註下，比傳統 TF–IDF 平均改善 macro F1 10.7–18.3 個百分點 [8]。本站目前零樣本 checkpoint 不等於該微調實驗；先測八類描述與拒絕規則，不預設增加 API 預算。

    The paper's 10.7–18.3 percentage-point macro F1 improvement concerns fine-tuning with 100–2,500 labels across eight tasks. It is not a result for the current zero-shot checkpoint. Test topic descriptions on separate development data first.

  5. 較重的 BGE-M3 模式暫列低優先

    MKQA 平均 Recall@100 為 dense 75.1、dense+sparse 75.3、all 75.5 [9]。該 learned sparse 不是本站 BM25；multi-vector 成本較高。保留現況，待本地相關性、RAM 及延遲支持再擴充。

    On MKQA, mean Recall@100 is 75.1, 75.3 and 75.5 for dense, dense+sparse and all modes. Learned sparse retrieval differs from BM25. Defer heavier modes until local quality, RAM and latency justify them.
